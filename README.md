## NumPy 100 题

[![Binder](http://mybinder.org/badge.svg)](http://mybinder.org:/repo/rougier/numpy-100/notebooks/100%20Numpy%20exercises.ipynb)

本项目汇集了来自 NumPy 邮件列表、Stack Overflow 和 NumPy 文档的练习题。为了凑足 100 道题，作者也自行编写了一些题目。本练习集旨在为新老用户提供便捷的参考，同时为教学提供一套练习材料。如需进一步练习，请阅读 [From Python to NumPy](http://www.labri.fr/perso/nrougier/from-python-to-numpy/)。

→ [在 Binder 上运行练习](http://mybinder.org:/repo/rougier/numpy-100/notebooks/100_Numpy_exercises.ipynb)

→ [在 GitHub 上阅读练习](100_Numpy_exercises.md)


注意：Markdown 文件和 Jupyter Notebook 均由程序根据 `source/exercises100.ktx` 中的源数据及 `source/headers.ktx` 中的公共说明生成。
如需修改这些文件的内容，请先修改对应源文件，再使用已安装 `requirements.txt` 中依赖的 Python 解释器运行 `generators.py` 模块。

键控文本格式（`ktx`）是一种简洁、便于阅读的键值格式，用于存储由键索引的文本（如 Markdown 等）。
